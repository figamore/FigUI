FluidNC machine axis mapping

Machine coordinate = joint angle × scale + zero. Configure FluidNC with Cartesian kinematics, one motor axis per joint. Scale is controller units per degree; a negative scale reverses direction. These values must match the calibrated physical robot.

Joint Axis Units / ° Zero · units

J6: 1.8° motor, 1/8 microstepping, no reducer. Default scale is 1 unit per degree, retaining the selected direction. Set its FluidNC axis to 4.444444 steps/mm separately, then apply configuration.

Applying configuration pauses machine control. Joint mapping, angle offset or home angle changes require a new reference; dimensions, tool and limit edits keep the reference. Compatible edits keep your waypoints. Geometry or limit changes that require clearing them ask for confirmation first.

Upright pose: upper arm and forearm straight up, wrist vertical, and tool flange pointing horizontally outward along the shoulder axis. Joint dimensions, limits and taught points are kept.

2. Keep the robot stationary and the controller Idle. Confirm when the physical arm matches. We will record the current six machine coordinates as this pose.

This records joint zero offsets in the plugin. It does not move the motors, send a homing command, or clear a firmware alarm. Repeat after a controller restart, lost steps, or moving the arm with the drives disabled.

From model to motion

  1. Define the robot. Setup → Configure dimensions & limits. Enter standard DH geometry, joint limits, velocity and acceleration limits, and base/tool transforms. The built-in samples use six revolute joints. Enter your arm's measured dimensions before connecting hardware.
  2. Teach and plan. Use joint sliders or solve a Cartesian target. Teach points as MoveJ or MoveL, reorder them, then plan and preview. MoveJ interpolates joints; MoveL interpolates TCP position and orientation. Each segment starts and ends at rest.
  3. Save your work. Your latest robot setup and workspace are remembered automatically in this browser. Save project also stores settings on the FigUI controller (or in browser storage when opened standalone). Export/import JSON transfers the complete project.
  4. Connect a physical arm. This plugin controls six independent FluidNC axes with calibrated machine positions. Verify scale, direction and firmware limits, then use Manual homing to align and confirm the reference pose before enabling the mapping. Hold to move sends a joint jog; release or Escape cancels it.
  5. Run a program. Export G-code or send it to FigUI’s file viewer for normal job execution. Start the machine at the program’s documented starting pose. Output uses G53 machine coordinates, native joint feeds in controller-maximum mode, and G93 inverse-time feeds for sampled paths.

Planning checks kinematic reachability and sampled joint limits. It does not model collisions, payload dynamics, or safety-rated stops. Use the physical emergency stop for an emergency. The 3D viewer is included locally and works offline with WebGL.
